    /* Поява під час прокручування: текст доступний, навіть якщо API не підтримується. */

    /* Після редагування CONFIG виконайте savePortfolioForSEO() у консолі браузера.
       Завантажиться index.html з актуальними текстами та метаданими навіть без JS. */
    window.savePortfolioForSEO = () => {
      const copy = document.documentElement.cloneNode(true);
      copy.querySelectorAll('.is-pending').forEach(el => el.classList.remove('is-pending'));
      copy.querySelectorAll('.is-visible').forEach(el => el.classList.remove('is-visible'));
      const toast = copy.querySelector('.pf-toast');
      if (toast) toast.textContent = '';
      const blob = new Blob(['<!DOCTYPE html>\n' + copy.outerHTML], { type: 'text/html;charset=utf-8' });
      const url = URL.createObjectURL(blob);
      const download = document.createElement('a');
      download.href = url; download.download = 'index.html';
      document.body.append(download); download.click(); download.remove();
      setTimeout(() => URL.revokeObjectURL(url), 2000);
    };

    const reduced = window.matchMedia('(prefers-reduced-motion: reduce)');
    let observer;
    const revealAll = () => {
      if (observer) observer.disconnect();
      document.querySelectorAll('.pf-reveal').forEach(el => { el.classList.remove('is-pending'); el.classList.add('is-visible'); });
    };
    if (C.motion.enabled && !reduced.matches && 'IntersectionObserver' in window) {
      observer = new IntersectionObserver(entries => {
        entries.forEach(entry => {
          if (!entry.isIntersecting) return;
          entry.target.classList.remove('is-pending');
          entry.target.classList.add('is-visible');
          observer.unobserve(entry.target);
        });
      }, { threshold: .08 });
      document.querySelectorAll('.pf-reveal').forEach(el => {
        if (el.getBoundingClientRect().top > window.innerHeight) { el.classList.add('is-pending'); observer.observe(el); }
      });
    }
    if (reduced.addEventListener) reduced.addEventListener('change', event => { if (event.matches) revealAll(); });
  })();
  </script>
</body>
</html>

ЧАСТИНА 2. ЩО І ДЕ ЗМІНЮВАТИ

1. ЯК ВИКОРИСТАТИ
Скопіюйте тільки код між позначками «ПОЧАТОК КОДУ» та «КІНЕЦЬ КОДУ», без самих позначок. Збережіть його як index.html у кодуванні UTF-8. Це повна односторінкова сторінка, а не фрагмент для вставлення всередину іншого HTML-документа. HTML, CSS та JavaScript уже містяться в одному файлі.
Для GitHub Pages додайте index.html у вибрану папку публікації репозиторію. У Settings → Pages налаштуйте джерело публікації. Сам TXT не відображатиметься як сайт — потрібен саме index.html. Публікація в GitHub у межах цього завдання не виконувалася.
Офіційна інструкція: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

2. ДЕ РЕДАГУВАТИ
На початку першого <script> знайдіть const CONFIG = { ... }.
Редагуйте значення справа від двокрапки; зберігайте лапки та коми. Біля всіх параметрів є коментарі «ЗМІНИТИ». Для переносу рядка в тексті використовуйте \n. Подвійні лапки всередині значення можна замінити українськими «ялинками» або екранувати як \".
Нижче також є автоматично сформована SEO-копія контенту. Її не потрібно редагувати вручну: спосіб оновлення описаний у пункті 8.

3. ВАШЕ ІМ’Я ТА ПЕРШИЙ ЕКРАН
brand.name — замість your.name впишіть ваше ім’я або назву студії.
brand.role — коротка спеціалізація.
hero.titleFirst, titleAccent, titleLast — три рядки головного заголовка; середній має акцентний колір.
hero.description — основний опис послуги.
hero.primaryLabel — текст головної кнопки; primaryUrl — її посилання. Початково кнопка веде до контактної секції.
hero.secondaryLabel / secondaryUrl — друга кнопка.
hero.note, asideLabel, asideText, stamp — допоміжні тексти.
hero.services — підписи етапів у нижній смузі.
navigation — тексти й адреси навігації.
footer — підпис унизу; рік оновлюється автоматично.
Не змінюйте внутрішні адреси #pf-top, #pf-work, #pf-contact, якщо не змінюєте відповідні id у коді.

4. ДВІ ВАШІ РОБОТИ
CONFIG.work.projects містить два об’єкти. Перший — ліва картка, другий — права; на телефоні вони йдуть одна під одною.
name — назва роботи; category — тип роботи; description — короткий опис.
url: "#" — замініть # на повне посилання на відповідну роботу. Обидві адреси зараз залишені як # на ваше прохання.
image: "" — вставте посилання на скриншот або шлях на кшталт ./images/project-1.webp.
alt — поруч із image; опишіть, що зображено. Приклад: «Головна сторінка сайту кав’ярні з меню та онлайн-замовленням».
imagePosition: "center" — обрізання по центру; "top" — показувати верх скриншота.
Рекомендовано скриншоти приблизно 1200 × 1000 px у WebP або AVIF; важливий контент розміщуйте ближче до центру. Зображення мають loading="lazy" та зарезервовану область.
Якщо image порожнє або файл не завантажується, показується демообкладинка. Її тексти: previewBrand, previewLabel, previewTitle, previewDetail, previewTag. Поточні forma / pulse — вигадані демонстраційні концепти, а не заявлені роботи для реальних клієнтів. Після додавання своїх робіт замініть також назви, описи та позначки.
За посилання # показується повідомлення work.placeholderNotice. Коли вкажете справжню адресу, картка відкриватиме її у тій самій вкладці.

5. КОНТАКТИ — ЗАПОВНІТЬ ПЕРЕД ПУБЛІКАЦІЄЮ
contact.buttonUrl — ваше посилання для звернень. Наприклад: https://t.me/ваш_нік або mailto:ваша@пошта.
contact.secondaryUrl — адреса для другого способу зв’язку, наприклад mailto:ваша@пошта.
contact.buttonLabel / secondaryLabel — відповідні тексти кнопок.
contact.title, description, note, eyebrow — тексти контактної секції.
Адреси контактів зараз також #, оскільки ви їх не надали. До заміни вони показують contact.placeholderNotice і не надсилають заявки. У цій версії немає форми чи сервера: відвідувач переходить у ваш месенджер або поштовий застосунок.

6. УСІ КОЛЬОРИ
CONFIG.colors:
background — фон сторінки; surface — панелі й повідомлення;
text — головний текст; muted — другорядний текст; line — рамки;
accent — лаймовий акцент, світла контактна секція та основні кнопки;

Колір стрілок, виділення тексту, клавіатурного фокусу та favicon також береться з цієї палітри. Кольори завантажених вами фотографій або скриншотів налаштування палітри не перефарбовують.
Після зміни палітри зберігайте читабельний контраст тексту і фону.

7. GOOGLE FONTS
fontHeading — точна назва Google Fonts для заголовків.
fontBody — точна назва Google Fonts для основного тексту та кнопок.
fontHeadingUrl / fontBodyUrl — HTTPS-адреси CSS Google Fonts. Вставляйте лише URL із дужок url(...) у запропонованому Google Fonts рядку @import, без <style>, @import і зовнішніх лапок.
Назва та URL мають відповідати одному шрифту. Обирайте шрифти з українською кирилицею та потрібними накресленнями.
Код сам створює або оновлює <style id="pf-google-fonts"> з @import та динамічно змінює font-family. Якщо Google Fonts недоступний, використовується системний sans-serif.

8. SEO І ОНОВЛЕННЯ СТАТИЧНОЇ КОПІЇ
headingLevel: "h1" — для окремої сторінки з цим першим екраном. Значення "h2" — якщо згодом інтегруєте секцію в сторінку, де H1 уже є. У файлі один H1, секції мають H2, назви робіт — H3. Обгортки трьох змістових блоків — <section>.
seo.title — назва сторінки у вкладці й метаданих; seo.description — опис сторінки; seo.language — мова, зараз uk.
seo.canonicalUrl — повна остаточна публічна адреса сторінки, включно зі шляхом репозиторію, якщо він є. Порожня адреса не додає canonical.
У готовому коді вже є статичні тексти й метадані, доступні без виконання JavaScript. Візуальний контент оновлюється з CONFIG під час відкриття сторінки.
ПІСЛЯ редагування CONFIG, перед завантаженням у GitHub, оновіть статичну копію:
  1) збережіть змінений index.html і відкрийте його у власному браузері;
  2) відкрийте інструменти розробника → Console;
  3) введіть savePortfolioForSEO() та натисніть Enter;
  4) браузер завантажить новий index.html. Саме цей файл завантажте в GitHub.
Ця вбудована команда зберігає поточний контент, кольори, шрифти й метадані разом із CONFIG. Зовнішніх сервісів та встановлення пакетів не потрібно. Повторюйте після подальших змін; інакше боти без JavaScript бачитимуть попередній статичний текст.
Це технічна SEO-підготовка, а не обіцянка позицій у пошуку.
Пояснення Google щодо JavaScript та попереднього рендерингу: https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics

9. АНІМАЦІЇ Й АДАПТИВНІСТЬ
motion.enabled: false — вимкнути анімації; true — увімкнути.
revealDuration — тривалість появи секцій у мілісекундах; hoverDuration — реакція на наведення.
Є поява елементів під час прокручування, зміщення стрілок, підняття кнопок, масштабування обкладинок і плавні переходи до секцій.
Системне налаштування «Зменшення руху» має пріоритет. Нескінченних анімацій, автоскролу та перехоплення курсора немає.
На вузьких екранах картки стають в одну колонку, допоміжний декор зникає, розміри заголовків зменшуються. Клавіатурний фокус помітний; є посилання для переходу до основного змісту.

10. ЩО ПЕРЕВІРЕНО
Перевірено синтаксис JavaScript, формування HTML із CONFIG, ієрархію заголовків, кількість робіт, підстановку кольорів і @import шрифтів. Увімкнення headingLevel: "h2" прибирає H1 з цього шаблону.
Візуальна перевірка у браузері тут не виконана: інструмент заблокував відкриття локального файлу. Перед публікацією перегляньте сторінку на телефоні й комп’ютері та перевірте власні контакти, зображення і посилання.
